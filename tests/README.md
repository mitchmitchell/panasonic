# Test data provenance

All test data, simulator responses and fixtures in this repository are synthetic. The
sign-on banner and prompts are placeholders (`<SIGNON_BANNER>`, `<MODE_START>`,
`<TERMINAL_IN_USE>`, a generic `Password:` prompt), and timings are generic values. Nothing
here is copied from a live capture, a factory database or a decompiled tool (clean room,
decision 74).
